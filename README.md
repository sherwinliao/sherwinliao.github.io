# Sherwin (Shiwei) Liao — Academic Portfolio

Static GitHub Pages site for `sherwinliao.github.io`.

## Publish

1. Remove the old repository files or overwrite them with the contents of this folder.
2. Keep `index.html`, `styles.css`, `.nojekyll`, and the complete `assets/` folder at the repository root.
3. In **Settings → Pages**, select **Deploy from a branch**, `main`, and `/(root)`.
4. Wait for the green **pages build and deployment** run, then open <https://sherwinliao.github.io/>.

The CV and minor thesis are served as PDFs so their layout and embedded figures remain stable. The two qualification PDFs are included unchanged.
